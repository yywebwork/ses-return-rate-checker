# SES還元率・職場環境チェック

SESエンジニア向けの無料チェックツールです。

自分の給与と契約単価から還元率を計算し、職場環境を3つの観点から確認できます。

## ツールはこちら

https://yywebwork.github.io/ses-return-rate-checker/

## できること

- 額面年収と契約単価から給与還元率を計算
- 会社負担分を概算で加えた還元率を計算
- 契約単価が不明な場合、経験年数別の参考単価から推定
- 8つの質問で職場環境をチェック
- 給与・還元、スキル成長、心身負荷の3軸で評価
- 結果をXで共有

## 使い方

1. 月給や賞与、契約単価などを入力します。
2. 職場環境に関する8つの質問に回答します。
3. 「結果をチェックする」を押します。
4. 還元率と職場環境の診断結果を確認します。
5. 必要に応じてXで結果を共有できます。

## 計算方法

**給与還元率**

額面年収 ÷ 年間契約金額 × 100

**会社負担込み還元率**

（額面年収 × 1.15）÷ 年間契約金額 × 100

※1.15は会社負担分を約15％と仮定した概算です。実際の負担額とは異なる場合があります。

## 注意事項

- 表示される契約単価は参考値であり、実際の契約単価を保証するものではありません。
- 相場は出典によって幅があるため、あくまで目安として利用してください。
- 還元率や職場環境の評価は、会社の良し悪しを断定するものではありません。
- 会社負担込み還元率は社会保険料などの概算であり、会社の経費すべてを含むものではありません。
